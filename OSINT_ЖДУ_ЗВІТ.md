### 5.1. Інститути та факультети (актуальний сайт)


| Тип       | Назва                                        |
| --------- | -------------------------------------------- |
| ННІ       | Іноземної філології                          |
| ННІ       | Педагогіки                                   |
| ННІ       | Філології та журналістики                    |

| Факультет | Фізичного виховання і спорту                 |
| Центр     | Доуніверситетської освіти та освіти дорослих |


### 5.2. Ключові підрозділи (з меню сайту)

Навчальний відділ, НМВ, відділ аспірантури, міжнародних зв’язків, моніторингу якості, бібліотека, студентський інформаційний центр, агробіостанція, науковий ліцей, юридична клініка «Правосвіт», кар’єр-центр, музеї, військова кафедра (співпраця з НУОУ).

### 5.3. Наукова інфраструктура (Вікіпедія + сайт)

- 17+ наукових шкіл, 20+ центрів, ~30 лабораторій (за Вікіпедією)
- Астрономічний НДЦ, агробіостанція, малакологічна школа
- Спеціалізовані вчені ради, рада докторів, рада молодих вчених

### 13.2. Зв’язок із експериментом Вінклера (ЛР2)

Зібрані OSINT-дані дозволяють відтворити логіку атаки з теоретичної частини:

1. Інтернет-пошук → імена керівництва та структура (**rectorat**, **новини**).
2. Телефонний довідник → номери відділів для «помилкових» дзвінків.
3. Публічні звіти → контекст проєктів і пріоритетів для правдоподібних запитів.
4. Соцмережі → імена учасників заходів, графік вступної кампанії.
5. ENTER / кабінети → цільові сервіси для фішингу «оновлення пароля».
